Kopfspiele

Kleine Spiele für zwischendurch. Such dir eins aus und knack deinen Rekord.

◼ Farben merken Merk dir die Farbfolge und klick sie nach. Jede Runde eine Farbe mehr. ⚡ Reaktion Warte, bis das Feld grün wird, und klick so schnell du kannst. # Zahlen-Blitz Eine Zahl blitzt kurz auf. Tipp sie nach. Jede Runde eine Ziffer mehr. ± Schnell-Rechnen 60 Sekunden, so viele Aufgaben wie möglich. Es wird immer schwerer.

Keine Anmeldung, keine Werbung, kein Tracking. Deine Rekorde werden nur in deinem Browser gespeichert.
